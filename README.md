## Learning Approach

This repo follows a project-based learning methodology, where theoretical knowledge from notes is applied through practical projects of increasing complexity. Each project builds upon previous concepts, ensuring a solid foundation in JavaScript development.

## Getting Started

1. Review the learning roadmap in `roadmap/learning-roadmap.md`
2. Start with foundational notes in `notes/javascript-core/`
3. Build confidence with mini-projects in `mini-projects/`
4. Tackle intermediate projects to deepen understanding
5. Challenge yourself with advanced projects
6. Maintain daily logs of learnings and insights in `daily-log/`

## Daily Log Format

Each daily log entry should include:
- Concepts learned
- Challenges faced
- Solutions implemented
- Key takeaways
- Next steps
